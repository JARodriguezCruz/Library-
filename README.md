# 📚 Library

Aplicación desarrollada en Java que simula la gestión de una biblioteca utilizando estructuras de datos como listas, mapas y conjuntos.

## 🚀 Características
- Gestión de libros, autores y usuarios
- Búsqueda y filtrado de libros
- Uso de Java Collections (List, Set, Map)
- Programación orientada a objetos (POO)

## 🛠️ Tecnologías
- Java
- Collections Framework
- Streams & Lambdas

## 📂 Estructura
- `model/` → Entidades (Libro, Autor, Usuario)
- `service/` → Lógica de negocio
- `main/` → Punto de ejecución

## ▶️ Ejecución
```bash
javac Main.java
java Main
